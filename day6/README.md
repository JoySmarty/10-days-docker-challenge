# Day 6 – Docker Compose 🐳

## What I learned
- Docker Compose helps manage multi-container applications
- How to define services using YAML
- How to run multiple containers with a single command

## What I did
- Created a docker-compose.yml file
- Defined two services (frontend and backend)
- Ran both containers using docker compose
- Accessed the frontend via browser

## Commands used
docker compose up -d
docker compose down

## Outcome
Successfully ran multiple containers using Docker Compose 🚀
