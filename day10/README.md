- Day 2: Running Containers (Nginx)

- Day 5: Networking (Container Communication)
- Day 6: Docker Compose
- Day 7: Environment Variables
- Day 8: Dockerizing an App
- Day 9: Compose + Build Integration
- Day 10: Final Project

## Outcome
Built a strong foundation in Docker and containerization, with hands-on projects and real-world concepts.
